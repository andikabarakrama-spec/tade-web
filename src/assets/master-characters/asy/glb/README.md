This directory is designated for canonical 3D GLB assets for **Asy** (Sahabat Santri Teladan).

- **Texture Format**: Optimized 512x512 / 1024x1024 KHR_texture_basisu / PNG

  2. `wave` (Greeting Salam)
  3. `readIqro` (Khusyuk Membaca)
